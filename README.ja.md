# dacapo

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · 日本語 ·
[한국어](README.ko.md)

_Da capo_ ――「はじめから」。

dacapoは、MIDIキーボードでピアノを練習するためのオープンソースのWebアプリです。本物の大譜表で譜読みを練習し、音ごとの反応時間を記録して、苦手な音をヒートマップで示します。本物の楽譜で曲も練習できます（待機モードとリズムモード）。データはすべてお使いのブラウザの中に保存されます。ログインすれば、自分の端末どうしで同期することもできます。

**今すぐ試す：** [playdacapo.com](https://playdacapo.com/) ――インストール不要、アカウントなしで使えます。

## できること

- **ピアノの基礎**：初心者のための15の短いレッスン。鍵盤、五線譜、目印の音、リズム、シャープとフラット、長音階、姿勢と手の形、付点・タイ・三連符、短調、強弱とアーティキュレーション、ペダル、装飾音、和音、練習のしかた、様式と形式を、実際に弾ける図と仕上げの練習問題で学べます。レッスンの最後からは、その内容に合った練習（ちょうどよいレベル、スケール、曲）をそのまま始められ、それぞれの練習のページには、はじめての人向けに対応するレッスンが示されます。終えたレッスンにはチェックが付き、ログインすればどの端末でも同じように表示されます。
- **画面の鍵盤**：88鍵の鍵盤が、弾いた音・強さ・ダンパーペダルに合わせて光ります。MIDIキーボード、パソコンのキーボード、マウスやタッチで弾けます。
- **譜読みのフラッシュカード**：大譜表に出た音を、オクターブも合わせて鍵盤で弾きます。中央Cのポジションから加線、シャープとフラットまで7つのレベル。解答ごとに正誤と時間を記録し、時間のかかる音や不確かな音を優先して出題します。譜読みには**楽典のカード**もあります。2つの音の音程を答える（ダブルシャープ・ダブルフラットまで）、調号の主音を弾く、和音を書かれたとおりに弾くか名前で答える、の3種類で、それぞれにレベルがあります。さらに**リズム**：1本線の譜表に書かれたリズムを、1小節の予備カウントのあとどの鍵盤でもいいのでタップし、すべての音をクリックと比べて計ります。4分音符からタイ、16分音符、3連符、シンコペーション、8分の6拍子、両手で2つのリズムまで10レベル。そして**初見**：大譜表に生成される初めて見る短い曲を、右手のCポジションからシャープかフラット4つまでの左手の和音まで8レベルで。数秒目を通してから、テンポどおりに一度弾き通します（下見として1音ずつ弾くこともできます）。弾いた小節を隠して先読みを鍛えることもでき、弾き終えると小節ごとの結果が見られます。
- **聴音**：音程と和音を耳で聴き分けます。オクターブ・5度・長3度から、複音程、転回形、七の和音まで12のレベル。楽器か内蔵ピアノが出題し、鍵盤で弾いて答える（最初の音か根音に印がつきます）か、名前で答えます。次の問題は間違えやすいものから出ます。**旋律**では調の主和音のあとに短い旋律が流れます。順次進行の3音から短調、半音階的な音まで7つのレベル。1音ずつ弾いて返し、間違えると旋律と弾いた音が五線に書かれます。**リズム**では1小節のクリックのあと、1つの鍵盤で1小節のリズムが鳴ります。譜読みのリズムの最初の8レベルで、拍に合わせてタップして返すか、リズム型が1つだけ違う小節の中から選んで答えます。**歌**では、内蔵のリードシート8曲の旋律をフレーズごとに聴いて弾きます。調の主和音のあとにフレーズが元のリズムで流れるので、1音ずつ弾いて返し、最後に曲全体を弾きます。原調でも、別の調でも（耳で移調する練習です）。間違えると、そのフレーズが五線に書かれ、弾いた音が正しい音の横に示されます。記録ページでは、問題の種類（聴音と楽典カード）ごとに、各レベル、特に苦手な項目、代わりに何と答えたかの表（例：「短6度を完全5度と答えた：12回中4回」）が見られます。
- **和声：コードネームから弾く**：リードシートのように書かれたコードネーム（`Am`、`G7`、`F/A`、`Dm7♭5`）の音を、好きなオクターブと配置で弾きます。分数コードはベースをいちばん下に。ハ長調・ト長調・ヘ長調の三和音から、12の根音の三和音と七の和音、分数コード、`°`・`+`・`sus`・`6`・`add9` まで5つのレベル。解答ごとに時間を計り、遅いものほど多く出題し、ヒントで構成音も表示できます。**コード進行**（`I–IV–V–I`、`ii7–V7–Imaj7`、12小節のブルースなど）はどの調でも楽譜になり、左手は伴奏形（ブロックコード、アルベルティ・バス、ワルツ、ストライドなど）、右手の和音はできるだけ動かさずにつながり、曲と同じように練習できます。聴音ページでは終止形も：4つの和音のあと、完全終止・変格終止・半終止・偽終止を答えます。**即興演奏**：ループする伴奏（12小節のブルース、`I–vi–IV–V`、`ii–V–I`、モーダル・ヴァンプ。ストレートかスウィング）の上で弾くと、コードが次々に表示され、鍵盤におすすめのスケールが示され、弾いた音はコードトーン・スケール音・スケール外で色分けされます。コール・アンド・レスポンスも。止めると採点ではなくフィードバックが出て、テイクを伴奏といっしょに再生できます。
- **苦手な音のヒートマップ**：譜表または鍵盤の上に、音を見つける速さを色で示します。
- **曲の練習**：パブリックドメインの31曲を収録（うち10曲は底本にした版の指使いつきの初歩の曲、8曲は、民謡・賛美歌・霊歌の旋律にコードネームをつけたリードシートで、左手は選んだ伴奏形でコードネームから作られ、ヘ音譜表に書かれます）。自分のMusicXMLもインポートできます。待機モードでは正しく弾くまでカーソルが待ち、リズムモードではメトロノームに合わせて弾いたあと、早い・遅いの傾向や速くなった小節がわかります。お手本ともう片方の手は楽器がMIDIで弾き、楽器にMIDI出力がなければ内蔵のサンプリング・グランドピアノ（Salamander Grand Piano）が弾きます。パソコンのキーボードや画面の鍵盤も、このピアノで鳴ります。どの演奏も弾いたとおりに再生でき、楽譜がついていき、ミスタッチは弾いた場所に示されます。楽譜どおりの音と1小節ずつ聴き比べることも、MIDIファイルとして保存してほかのソフトで聴いたり先生に送ったりすることもできます。最後まで弾いた曲は、1日後、2日後、4日後、1週間後と、うまく弾けている間は最長2か月まで間隔を空けて復習に戻ってきます。暗譜モードでは楽譜が小節ごとに消えていき、必要なときだけのぞけます。どの曲も上下6半音まで移調でき、楽譜は新しい調で描き直され、お手本も伴奏も判定もその調になります。弾き終えると、次に何を練習するかを一文で示し、ボタンひとつでその設定になります。片手ずつ、数小節のループ、テンポを落とす、あるいはテンポを10%ずつ上げて楽譜のテンポまで進む、といった内容です。曲のページは次に取り組む曲も示します。練習中の曲か、到達したグレードでまだ始めていない最初の曲です。
- **スケール**：すべての調の長音階、3種類の短音階、半音階、長三和音・短三和音のアルペジオを1〜4オクターブ、片手、両手、または同じ主音から始める反行で。ハノンの運指つきです。自分のテンポでも、クリックに合わせても（♩ = 40〜160、1拍に2・3・4音、1小節の予備カウントつき）弾けます。弾いたあとは、時間の粒のそろい（プロのピアニストの8〜9ミリ秒と比べて）、強さとレガート、親指くぐりの遅れや早さがわかり、クリックに合わせたときは早め・遅めの傾向も出ます。苦手な箇所は前後数音をループで練習できます。すべての演奏を記録し、スケールごとの30日の推移と次に練習するスケールを示します。弾き終えると、次に何を練習するか（ある場所の前後のループ、片手ずつ、弾き始めのテンポでクリックに合わせる、次のテンポへ進む）を一文で示し、ボタンひとつでその設定になります。
- **テクニック**：すべての調の5指の練習、ハノンの第1〜20番（音符も小節も運指も1900年版の楽譜どおりで、2回書き起こして照合済み）、主和音の和音（2〜3オクターブ）と分散和音（1〜2オクターブ）、同じ本から七の和音のアルペジオ、同音連打、トリル、3度の重音、オクターブ（24の調のオクターブの音階）、さらに好きな調・好きな2本の指のトリル。測り方はスケールと同じで、和音は最初の鍵盤で時間を測り、鍵盤どうしのずれといちばん上の音が目立っていたかもわかります。トリルは速さの移り変わりと2本の指のそろい、同音連打はもう一度弾く前に鍵盤がどれだけ上がっていたかがわかります。ハノンの音型では、各グループの同じ位置の音を指摘します。
- **メトロノーム**：メルツェル式の振り子が、聞こえる拍でちょうど中央を通り、おもりはテンポに合わせて上下します。20〜300 BPM、タップでテンポ設定、拍子、アクセントとミュート、細分、3種類の音色、音なし（表示のみ）、だんだん速くする・無音小節をはさむテンポトレーナー。演奏・譜読み・曲の練習中はヘッダーのボタンで操作でき、曲のテンポにもワンクリックで合わせられます。リズムモードでは自動で一時停止します。
- **はじめに**：「はじめる」を押すと、どこから始めるか（ピアノは初めてか、もう弾けるならどこまで読めるか）を聞き、弾いた鍵盤が届いているかを確かめられます。音のテストもできます。もう弾ける人にはすべての練習が最初から開いていて、譜読みは読めるところの先から始まります。MIDIキーボードがつながっていないときは、練習ページごとに何で弾けるかを1行で示します。
- **今日**：一度練習すると、ホームには自分の記録から作った今日の練習メニューが出ます。ウォームアップのスケール、練習中の曲、次のレッスンと、しばらく触れていない練習のおすすめレベル、復習の時期が来た曲を、10〜45分の長さで。各項目はクリックで始められ、弾くと自動でチェックが付きます。「記録」ページの「現在地」では、練習ごとの進み具合と次の一歩がわかります。
- **練習の記録**：今日の練習時間、連続日数（1日5分、または自分で決めた目標。最長45分で、目標を変えてもそれまでの日は変わりません）、過去30日のグラフ。「先週」には1週間の結果（練習した日数と時間、習得したレベル、復習に入った曲、到達したテンポ）が、今週のここまでと並んで出ます。週が替わると、ホームにも1行で表示します。「上達の様子」では練習ごとに直近半年を週単位でグラフにし（譜読みの速さ、初見演奏、楽典、聴音、リズムの聴音、コードネーム、リズムの正確さ、スケールの粒のそろい方、曲を1回目で正しく弾けた割合）、直近4週がその前の4週と比べてどうかを言葉で示します。レベルが異なるときはレベルごとに比べます。
- **課題**：先生（保護者でも、自分でも）が1週間の練習を項目にして出します。曲の小節・手・モード・テンポ、クリックに合わせたスケール、譜読み・聴音・和声のレベル、レッスン、1日の練習時間。課題はサーバーを介さず、リンクかファイルで共有します（内容はリンクそのものに入っています）。開いた人にはチェックリストが届き、弾いた内容に応じて自動でチェックが付き、各項目のボタンからその設定のまま始められます。次のレッスンには、同じ方法でレポートを返せます（項目ごとの達成状況、最高と直近の演奏、1日ごとの練習時間）。課題もレポートも印刷できます。
- 表示言語はEnglish、简体中文、繁體中文、日本語、한국어。音名はどの言語でも英字（C4、F♯）が基本で、設定でドレミ（ド4、ファ♯）に切り替えられます。

## 必要なもの

- パソコンのChromeまたはEdge（Web MIDIに対応）。ほかのブラウザでも、パソコンのキーボードやマウスで弾けます。
- MIDIキーボードはおすすめですが、必須ではありません。USBケーブルでつなぐだけです。
- アカウントは必要ありません。データは「設定」からJSONファイルにエクスポートして、バックアップや別のパソコンへの移行に使えます。
- 一度開けば、ネットワークがなくても開いて使えます。ウェブ版は端末に保存され、ChromeとEdgeではアプリとしてインストールすることもできます。「曲」と「スケール」の楽譜エンジン、内蔵ピアノ、ほかの言語は最初に使ったときに保存され、「設定」の「すべて保存」でまとめて保存することもできます。
- playdacapo.comはCloudflare Web Analyticsで訪問数を数えています。Cookieは使わず、個人データも練習の記録も集めません。Appleのアプリやほかのビルドには分析機能はありません。
- メールアドレスと届いたコードでログインすると、dacapoの同期サービスを通じて自分の端末どうしで練習が同期されます（[プライバシーポリシー](https://playdacapo.com/privacy)）。「設定」でアカウントを削除すると、サービス上のデータはすべて消去されます。
- ログインすると、GitHubのプロフィールのように1年分の練習を見せる公開ページも作れます。公開するのは練習のグリッドだけにも、毎日何を練習したかまで含めることもできます。自分でオンにするまでは公開されません（[docs/PROFILE.md](docs/PROFILE.md)）。

## 開発

Node.js 22.13以上とpnpm（バージョンは`package.json`の`packageManager`）が必要です。

```sh
pnpm install
pnpm dev
```

正式な説明は英語の[README](README.md)です。貢献の方法は[CONTRIBUTING.md](CONTRIBUTING.md)（英語）、翻訳については[docs/TRANSLATING.md](docs/TRANSLATING.md)をご覧ください。
