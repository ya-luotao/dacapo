# dacapo

[한국어](README.ko.md)

_Da capo_ ――「はじめから」。

dacapoは、MIDIキーボードでピアノを練習するためのオープンソースのWebアプリです。本物の大譜表で譜読みを練習し、音ごとの反応時間を記録して、苦手な音をヒートマップで示します。本物の楽譜で曲も練習できます（待機モードとリズムモード）。データはすべてお使いのブラウザの中にだけ保存されます。

**今すぐ試す：** [ya-luotao.github.io/dacapo](https://ya-luotao.github.io/dacapo/) ――インストールもアカウント登録も不要です。

## できること

- **画面の鍵盤**：88鍵の鍵盤が、弾いた音・強さ・ダンパーペダルに合わせて光ります。MIDIキーボード、パソコンのキーボード、マウスやタッチで弾けます。
- **譜読みのフラッシュカード**：大譜表に出た音を、オクターブも合わせて鍵盤で弾きます。中央Cのポジションから加線、シャープとフラットまで7つのレベル。解答ごとに正誤と時間を記録し、時間のかかる音や不確かな音を優先して出題します。
- **苦手な音のヒートマップ**：譜表または鍵盤の上に、音を見つける速さを色で示します。
- **曲の練習**：パブリックドメインの6曲を収録。自分のMusicXMLもインポートできます。待機モードでは正しく弾くまでカーソルが待ち、リズムモードではメトロノームに合わせて弾いたあと、早い・遅いの傾向や速くなった小節がわかります。お手本ともう片方の手は楽器がMIDIで弾き、楽器にMIDI出力がなければ内蔵のサンプリング・グランドピアノ（Salamander Grand Piano）が弾きます。パソコンのキーボードや画面の鍵盤も、このピアノで鳴ります。
- **メトロノーム**：メルツェル式の振り子が、聞こえる拍でちょうど中央を通り、おもりはテンポに合わせて上下します。20〜300 BPM、タップでテンポ設定、拍子、アクセントとミュート、細分、3種類の音色、音なし（表示のみ）、だんだん速くする・無音小節をはさむテンポトレーナー。演奏・譜読み・曲の練習中はヘッダーのボタンで操作でき、曲のテンポにもワンクリックで合わせられます。リズムモードでは自動で一時停止します。
- **練習の記録**：今日の練習時間、連続日数、過去30日のグラフ。
- 表示言語はEnglish、简体中文、繁體中文、日本語、한국어。音名はどの言語でも英字（C4、F♯）です。

## 必要なもの

- パソコンのChromeまたはEdge（Web MIDIに対応）。ほかのブラウザでも、パソコンのキーボードやマウスで弾けます。
- MIDIキーボードはおすすめですが、必須ではありません。USBケーブルでつなぐだけです。
- アカウントもサーバーもありません。データは「設定」からJSONファイルにエクスポートして、バックアップや別のパソコンへの移行に使えます。

## 開発

Node.js 22.13以上とpnpm（バージョンは`package.json`の`packageManager`）が必要です。

```sh
pnpm install
pnpm dev
```
