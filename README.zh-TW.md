# dacapo

[한국어](README.ko.md)

_Da capo_——「從頭開始」。

dacapo 是一個開放原始碼的鋼琴練習網頁應用程式，搭配 MIDI 鍵盤使用：在真正的大譜表上練習識譜，記錄你找到每個音的反應時間，用熱度圖標出最弱的音，還能在真正的樂譜上練樂曲（等待模式和節奏模式）。所有資料都儲存在你的瀏覽器裡；登入後可以在你自己的各個裝置之間同步。

**線上試用：** [playdacapo.com](https://playdacapo.com/)——不用安裝，也不用註冊。

## 功能

- **音符閃卡**：大譜表上出現一個音，在琴上彈出它，八度也要對。共七個等級，從中央 C 位置到加線和升降記號；每次作答都會記錄對錯和用時，下一張會優先出你較慢或還不熟的音。識譜還有**樂理閃卡**：說出兩個音之間的音程（到重升、重降記號為止），彈出調號的主音，照譜彈出或說出和弦，各有自己的等級。還有**節奏**：單線譜上的一行節奏，聽一小節預備拍後隨便按一個鍵打出來，每個音都對照節拍聲計時；十個等級，從四分音符到連結線、十六分音符、三連音、切分音、6/8 拍，再到雙手打兩種節奏。還有**視奏**：在大譜表上產生從沒見過的短曲，八個等級，從右手 C 位置到四個升降記號以內的左手和弦；先看幾秒，再跟著拍子一口氣彈下來（也可以一個音一個音地彈，先熟悉一下），可以讓彈過的小節被蓋住、逼自己往前看，彈完逐小節看結果。
- **練耳**：用耳朵分辨音程與和弦，共十二個等級，從八度、五度和大三度到複音程、轉位和七和弦。由你的樂器或內建鋼琴出題，你在琴上彈出來（第一個音或根音會標出來），或是選出名稱；下一題會優先出你常答錯的。**旋律**一項先奏出調的主和弦，再放一段短旋律，七個等級，從級進的三個音到小調和變化音；把它一個音一個音地彈出來，彈錯時會在五線譜上畫出旋律和你彈的音。**節奏**一項先響一小節節拍聲，再在一個鍵上放出一小節節奏，用識譜中節奏練習的前八個等級：跟著拍子把它打出來，或是從幾個只差一個節奏型的小節裡選出它。在進度頁面，每類題目（練耳和樂理閃卡）都會列出各等級、最弱的幾項，以及一張「你答成了什麼」的表格（例如「小六度答成了純五度：12 次中 4 次」）。
- **和聲：照和弦記號彈和弦**：像歌本那樣印出的和弦記號（`Am`、`G7`、`F/A`、`Dm7♭5`），在任意八度、用任意排列彈出它的音，斜線和弦要讓低音在最低。五個等級，從 C、G、F 大調的三和弦，到十二個根音上的三和弦、七和弦、斜線和弦以及 `°`、`+`、`sus`、`6`、`add9` 和弦；每次作答都會計時，下一張會優先出你較慢的，也可以打開提示顯示和弦音。**和弦進行**（`I–IV–V–I`、`ii7–V7–Imaj7`、十二小節藍調等）可以在任何調寫成樂譜，左手選一種伴奏型（柱式和弦、阿爾貝蒂低音、圓舞曲、跨步低音……），右手的和弦每次盡量少移動，然後像樂曲一樣練習。練耳頁面還能聽辨終止式：四個和弦之後，說出是正格、變格、半終止還是阻礙終止。**即興**：伴奏循環彈奏一組和弦（十二小節藍調、`I–vi–IV–V`、`ii–V–I`、調式循環，平均或搖擺八分），和弦隨時顯示，鍵盤上標出建議的音階，每個音按和弦內音、音階音或音階外著色；還有呼應練習。停下後給你回饋而不是分數，錄下的演奏可以連同伴奏回放。
- **弱點熱度圖**：在五線譜或鍵盤上，依你找到每個音的速度上色。
- **樂曲練習**：內建十三首公共領域的樂曲，也可以匯入自己的 MusicXML。等待模式下游標會等你彈對；節奏模式有節拍器，彈完會告訴你偏早還是偏晚、在哪幾個小節越彈越快。示範和另一隻手由你的樂器透過 MIDI 彈奏；樂器沒有 MIDI 輸出時，由內建的取樣平台鋼琴（Salamander Grand Piano）彈奏，電腦鍵盤和螢幕琴鍵也用它發聲。
- **音階**：各調的大調、三種小調、半音階和大小調琶音，一到四個八度，單手、雙手或從同一個主音出發的雙手反向，標有哈農（Hanon）的指法。可以按自己的速度彈，也可以跟著節拍器彈（♩ = 40–160，每拍兩、三或四個音，先有一小節預備拍）。彈完能看到時間上有多平均（對照職業鋼琴家的 8–9 毫秒）、力度和圓滑奏如何、拇指穿過的地方是早是晚；跟節拍器時還能看到你偏早還是偏晚。弱點可以截取前後幾個音循環練習。每一遍都會保存，並有 30 天趨勢和下一條建議練習的音階。
- **技巧練習**：各調的五指練習；哈農《鋼琴技巧練習》前二十首，音符、小節和他的指法都照 1900 年版原樣（轉錄兩遍並核對過）；主三和弦的柱式和弦（兩到三個八度）與分解和弦（一到兩個八度）；還有同一本書裡的七和弦琶音、同音反覆、顫音、三度雙音和八度（24 個調的八度音階），以及任意調、任意兩指的顫音。測法和音階一樣；和弦以最先按下的鍵計時，還能看到各鍵錯開了多少、最高音是否突出；顫音能看到頻率隨時間的變化和兩個手指是否均勻；同音反覆能看到每次重複前鍵抬起了多久；在哈農的音型裡，指出的是每組中的同一個音。
- **節拍器**：梅爾策爾式擺錘在你聽到的拍點正好擺過中線，滑錘位置隨速度升降；20–300 BPM，點按測速、拍號、重音與靜音拍、細分、三種音色、只看不響，還有漸快和靜音小節兩種速度訓練。彈奏、識譜和練習樂曲時，頁首的小按鈕就能開關，並可一鍵設為樂曲的速度；節奏模式會先暫停它。
- **練習紀錄**：今天的分鐘數、連續練習天數和最近 30 天的圖表。「練得怎麼樣」按週畫出每項練習最近半年的變化（識譜速度、視奏、樂理、練耳、聽節奏、和弦記號、節奏準度、音階的均勻度、樂曲第一次就彈對的比例），並用文字說明最近四週和之前四週相比如何，等級不同時按等級分別比較。
- 介面支援 English、简体中文、繁體中文、日本語、한국어。所有語言的音名都用字母（C4、F♯）。

## 使用需求

- 電腦上的 Chrome 或 Edge（支援 Web MIDI）。其他瀏覽器可以用電腦鍵盤或滑鼠彈奏。
- 建議使用 MIDI 鍵盤（以 USB 線連接），但不是必要的。
- 不需要帳號。資料可以在「設定」中匯出成 JSON 檔案，用來備份或搬到另一台電腦。
- playdacapo.com 使用 Cloudflare Web Analytics 統計造訪量：不用 cookie，不收集個人資料，也不涉及你的練習紀錄。Apple app 和其他建置都沒有統計。
- 也可以用電子郵件和驗證碼登入，透過 dacapo 的同步服務在你的各個裝置之間同步練習（[隱私權政策](https://playdacapo.com/privacy)）。在「設定」中刪除帳號，會清除服務上的所有資料。
- 登入後還可以發布一個公開個人頁面，像 GitHub 個人頁面那樣展示你一年的練習：可以只公開練習圖，也可以一併公開每天練了什麼。預設關閉，由你決定是否開啟（[docs/PROFILE.md](docs/PROFILE.md)）。

## 開發

需要 Node.js 22.13 以上和 pnpm（版本見 `package.json` 的 `packageManager`）：

```sh
pnpm install
pnpm dev
```
