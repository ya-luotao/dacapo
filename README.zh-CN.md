# dacapo

[English](README.md) · 简体中文 · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) ·
[한국어](README.ko.md)

_Da capo_——“从头开始”。

dacapo 是一个开源的钢琴练习网页应用，配合 MIDI 键盘使用：在真正的大谱表上做识谱练习，记录你每个音的反应时间，用热力图标出最薄弱的音，还能在真正的乐谱上练曲子（等待模式和节奏模式）。所有数据都保存在你的浏览器里；登录后可以在你自己的各台设备之间同步。

**在线试用：** [playdacapo.com](https://playdacapo.com/)——无需安装，无需注册。

## 功能

- **入门基础**：十五节给初学者的短课：键盘、五线谱、地标音、节奏、升降号、大调音阶、坐姿手型，以及附点、延音线、三连音、小调、强弱奏法、踏板、装饰音、和弦，还有怎样练琴、风格与曲式，配有可以动手弹的图示和收尾的练习。每一课学完，可以直接进入它对应的练习（合适的级别、音阶或曲目）；各项练习也会告诉新手该先看哪一课；学完的课会打勾，登录后在你的各台设备上都看得到。
- **识谱卡片**：大谱表上出现一个音，在琴上弹出它，八度也要对。七个级别，从中央 C 位置到加线和升降号；每次作答都记录对错和用时，下一张会优先出你慢或不熟的音。识谱还有**乐理卡片**：说出两个音之间的音程（到重升、重降为止），弹出调号的主音，按谱弹出或说出和弦，各有自己的级别。还有**节奏**：单线谱上的一行节奏，听一小节预备拍后随便按一个键打出来，每个音都对照节拍声计时；十个级别，从四分音符到延音线、十六分音符、三连音、切分音、6/8 拍，再到双手打两种节奏。还有**视奏**：在大谱表上生成从没见过的短曲，八个级别，从右手 C 位置到四个升降号以内的左手和弦；先看几秒，再跟着拍子一口气弹下来（也可以一个音一个音地弹，先熟悉一下），可以让弹过的小节被盖住、逼自己往前看，弹完逐小节看结果。一组卡片结束后，点**练这几个**，就只练刚才弹错和反应慢的那几项；刚好掌握了一个级别，或者这一级跳得太早，小结也会告诉你。
- **练耳**：靠耳朵辨认音程与和弦，十二个级别，从八度、五度和大三度到复音程、转位和七和弦。由你的乐器或内置钢琴出题，你在琴上弹出来（第一个音或根音会标出），或者选出名称；下一题会优先出你常错的；一组结束后，点**练这几个**，只练刚才答错的。**旋律**一项先奏出调的主和弦，再放一段短旋律，七个级别，从级进的三个音到小调和变化音；把它一个音一个音地弹出来，弹错时会在五线谱上画出旋律和你弹的音。**节奏**一项先响一小节节拍声，再在一个键上放出一小节节奏，用识谱中节奏练习的前八个级别：跟着拍子把它打出来，或者从几个只差一个节奏型的小节里选出它。**歌曲**一项把内置的八首旋律谱一句一句放给你听：先响起调的主和弦，再按原来的节奏放一个乐句，你把它一个音一个音地弹出来，最后弹整首歌；可以用原调，也可以换个调，这就是靠耳朵移调。弹错时会在五线谱上画出这个乐句，你弹的音标在正确的音旁边。在进度页面，每类题目（练耳和乐理卡片）都会列出各级别、最薄弱的几项，以及一张“你答成了什么”的表格（例如“小六度答成了纯五度：12 次中 4 次”）。
- **和声：照和弦记号弹和弦**：像歌本那样印出的和弦记号（`Am`、`G7`、`F/A`、`Dm7♭5`），在任意八度、用任意排列弹出它的音，斜线和弦要让低音在最低。五个级别，从 C、G、F 大调的三和弦，到十二个根音上的三和弦、七和弦、斜线和弦以及 `°`、`+`、`sus`、`6`、`add9` 和弦；每次作答都计时，下一张会优先出你慢的，也可以打开提示显示和弦音。**和弦进行**（`I–IV–V–I`、`ii7–V7–Imaj7`、十二小节布鲁斯等）可以在任意调写成乐谱，左手选一种伴奏型（柱式和弦、阿尔贝蒂低音、圆舞曲、跨步低音……），右手的和弦每次尽量少移动，然后像曲子一样练。练耳页面还能听辨终止式：四个和弦之后，说出是正格、变格、半终止还是阻碍终止。**即兴**：伴奏循环弹奏一组和弦（十二小节布鲁斯、`I–vi–IV–V`、`ii–V–I`、调式循环，平均或摇摆八分），和弦随时显示，键盘上标出建议的音阶，每个音按和弦内音、音阶音或音阶外着色；还有呼应练习。停下后给你反馈而不是分数，录下的演奏可以连同伴奏回放。
- **薄弱音热力图**：在五线谱或键盘上，按你找到每个音的速度着色。
- **曲目练习**：内置三十一首公版曲目（其中十首是带所据版本指法的入门小曲，八首是带和弦记号的民歌、赞美诗和灵歌旋律谱，左手由和弦记号按你选的伴奏型生成，写在低音谱表上），也可以导入自己的 MusicXML。等待模式下光标会等你弹对；节奏模式有节拍器，弹完告诉你偏早还是偏晚、在哪几小节越弹越快。示范和另一只手由你的乐器通过 MIDI 弹奏；乐器没有 MIDI 输出时，由内置的采样三角钢琴（Salamander Grand Piano）弹奏，电脑键盘和屏幕琴键也用它发声。每一遍都能按你弹的样子回放，乐谱跟着走，错音标在弹错的地方；还能和按谱弹的一小节一小节地对照，或者存成 MIDI 文件，在别的软件里听，发给老师。完整弹过的曲目会定期回来复习：先隔一天，再隔两天、四天、一周，弹得好就一直延长到两个月。背谱模式会让乐谱一小节一小节地隐去，需要时可以偷看一眼。每首曲子都可以移调，最多上移或下移六个半音：乐谱按新调重画，示范、伴奏和评判都跟着移。每弹完一遍，会用一句话告诉你接下来练什么，并有按钮一键设好：分手练、循环几小节、放慢速度，或者沿着速度阶梯每次加 10%，直到乐谱的速度。曲库会告诉你接下来练哪一首：正在练的那首，或者你已到达的级别里还没开始的第一首。每首曲子还有一份计划：一句一句地练，先分手，再合手，再跟着拍子，最后整首；按你的练习记录打勾，下一步一键开始。
- **音阶**：各调的大调、三种小调、半音阶和大小调琶音，一到四个八度，单手、双手或从同一个主音出发的双手反向，标有哈农（Hanon）的指法。可以按自己的速度弹，也可以跟着节拍器弹（♩ = 40–160，每拍两、三或四个音，先有一小节预备拍）。弹完能看到时间上有多均匀（对照职业钢琴家的 8–9 毫秒）、力度和连奏如何、拇指穿过的地方是早是晚；跟节拍器时还能看到你偏早还是偏晚。薄弱的地方可以截取前后几个音循环练习。每一遍都会保存，并有 30 天趋势和下一条建议练习的音阶。每弹完一遍，还会用一句话告诉你接下来练什么（循环练某个地方、先分手练、按开头的速度跟节拍器，或者再快一档），并有按钮一键设好。
- **技巧练习**：各调的五指练习；哈农《钢琴技巧练习》前二十首，音符、小节和他的指法都照 1900 年版原样（转录两遍并核对过）；主三和弦的柱式和弦（两到三个八度）与分解和弦（一到两个八度）；还有同一本书里的七和弦琶音、同音反复、颤音、三度双音和八度（24 个调的八度音阶），以及任意调、任意两指的颤音。测法和音阶一样；和弦以最先按下的键计时，还能看到各键错开了多少、最高音是否突出；颤音能看到频率随时间的变化和两个手指是否均匀；同音反复能看到每次重复前键抬起了多久；在哈农的音型里，指出的是每组中的同一个音。
- **节拍器**：梅尔策尔式摆锤在你听到的拍点正好摆过中线，滑块位置随速度升降；20–300 BPM，敲击测速、拍号、重音与静音拍、细分、三种音色、只看不响，还有逐渐加快和静音小节两种速度训练。弹奏、识谱和练曲时，页头的小按钮就能开关，并可一键设为曲目的速度；节奏模式会先暂停它。
- **第一次来**：点“开始”，先说说你从哪里开始（刚学钢琴，还是已经会弹、谱能认到哪一步），再看看按下的键有没有被听到，顺便试一下声音。已经会弹的人，所有练习直接开放，识谱从自己认得的地方往后开始。没有连接 MIDI 键盘时，每个练习页都会说明现在用什么弹。
- **今天**：练过之后，首页会按你自己的练习记录排出当天的计划：热身的音阶、正在练的曲目、下一节入门课和搁得最久的那项练习的建议级别，再加上待复习的曲目，10 到 45 分钟任选。每一步点一下就开始，练过自动打勾。进度页的“练到哪儿了”列出每项练习进行到了哪里、下一步是什么。
- **练习记录**：今日分钟数、连续打卡天数（每天 5 分钟，也可以自己定目标，最多 45 分钟；改目标不会改写之前的日子）和最近 30 天的图表。“上周”列出一周的结果（练了几天、多久，掌握了哪些级别，哪些曲目加入复习，达到了什么速度），旁边是本周到目前为止的情况；新的一周开始时，首页会用一行字告诉你。“练得怎么样”按周画出每项练习最近半年的变化（识谱速度、视奏、乐理、练耳、听节奏、和弦记号、节奏准度、音阶的均匀度、曲目第一次就弹对的比例），并用文字说明最近四周和之前四周相比如何，级别不同时按级别分别比较。
- **作业**：老师（或者家长，或者你自己）把一周的练习布置成一项项任务：曲目的哪几小节、哪只手、什么模式和速度，跟节拍器弹的音阶，识谱、练耳、和声的某个级别，一节入门课，每天练多少分钟。作业用链接或文件分享，不经过任何服务器：内容就装在链接里。打开的人会得到一份清单，练了什么就自己打勾，每项任务都有一个按钮，按它的设置直接开始。下次上课前，再用同样的办法发回一份报告：每项任务的进度、最好和最近的一遍、每天练了多少分钟。作业和报告都可以打印。
- 界面支持 English、简体中文、繁體中文、日本語、한국어。音名在所有语言里默认用字母（C4、F♯），也可以在设置里改用 Do Re Mi（Do4、Fa♯）。

## 使用要求

- 电脑上的 Chrome 或 Edge（支持 Web MIDI）。其他浏览器可以用电脑键盘或鼠标弹。
- MIDI 键盘推荐但不是必需的，用 USB 线连接即可。
- 不需要账号。数据可以在“设置”里导出为 JSON 文件备份或迁移。
- 打开过一次之后，没有网络也能打开和使用：网页版会保存在设备上，Chrome 和 Edge 还可以把它安装成应用。“曲目”和“音阶”的记谱引擎、内置钢琴和其他语言在第一次用到时保存，也可以在“设置”里用“全部保存”一次存好。
- playdacapo.com 用 Cloudflare Web Analytics 统计访问量：不用 cookie，不收集个人数据，也不涉及你的练习记录。Apple app 和其他构建都没有统计。
- 也可以用邮箱和验证码登录，通过 dacapo 的同步服务在你的各台设备之间同步练习（[隐私政策](https://playdacapo.com/privacy)）。在“设置”里删除账号会清除服务上的全部数据。
- 登录后还可以发布一个公开主页，像 GitHub 个人主页那样展示你一年的练习：可以只公开练习图，也可以同时公开每天练了什么。默认关闭，由你决定是否开启（[docs/PROFILE.md](docs/PROFILE.md)）。

## 开发

需要 Node.js 22.13 以上和 pnpm（版本见 `package.json` 的 `packageManager`）：

```sh
pnpm install
pnpm dev
```
