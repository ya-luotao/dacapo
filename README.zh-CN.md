# dacapo

_Da capo_——“从头开始”。

dacapo 是一个开源的钢琴练习网页应用，配合 MIDI 键盘使用：在真正的大谱表上做识谱练习，记录你每个音的反应时间，用热力图标出最薄弱的音，还能在真正的乐谱上练曲子（等待模式和节奏模式）。所有数据都保存在你的浏览器里；登录后可以在你自己的各台设备之间同步。

**在线试用：** [playdacapo.com](https://playdacapo.com/)——无需安装，无需注册。

## 功能

- **识谱卡片**：大谱表上出现一个音，在琴上弹出它，八度也要对。七个级别，从中央 C 位置到加线和升降号；每次作答都记录对错和用时，下一张会优先出你慢或不熟的音。识谱还有**乐理卡片**：说出两个音之间的音程（到重升、重降为止），弹出调号的主音，按谱弹出或说出和弦，各有自己的级别。还有**节奏**：单线谱上的一行节奏，听一小节预备拍后随便按一个键打出来，每个音都对照节拍声计时；十个级别，从四分音符到延音线、十六分音符、三连音、切分音、6/8 拍，再到双手打两种节奏。
- **练耳**：靠耳朵辨认音程与和弦，十二个级别，从八度、五度和大三度到复音程、转位和七和弦。由你的乐器或内置钢琴出题，你在琴上弹出来（第一个音或根音会标出），或者选出名称；下一题会优先出你常错的。**旋律**一项先奏出调的主和弦，再放一段短旋律，七个级别，从级进的三个音到小调和变化音；把它一个音一个音地弹出来，弹错时会在五线谱上画出旋律和你弹的音。在进度页面，每类题目（练耳和乐理卡片）都会列出各级别、最薄弱的几项，以及一张“你答成了什么”的表格（例如“小六度答成了纯五度：12 次中 4 次”）。
- **和声：照和弦记号弹和弦**：像歌本那样印出的和弦记号（`Am`、`G7`、`F/A`、`Dm7♭5`），在任意八度、用任意排列弹出它的音，斜线和弦要让低音在最低。五个级别，从 C、G、F 大调的三和弦，到十二个根音上的三和弦、七和弦、斜线和弦以及 `°`、`+`、`sus`、`6`、`add9` 和弦；每次作答都计时，下一张会优先出你慢的，也可以打开提示显示和弦音。
- **薄弱音热力图**：在五线谱或键盘上，按你找到每个音的速度着色。
- **曲目练习**：内置十三首公版曲目，也可以导入自己的 MusicXML。等待模式下光标会等你弹对；节奏模式有节拍器，弹完告诉你偏早还是偏晚、在哪几小节越弹越快。示范和另一只手由你的乐器通过 MIDI 弹奏；乐器没有 MIDI 输出时，由内置的采样三角钢琴（Salamander Grand Piano）弹奏，电脑键盘和屏幕琴键也用它发声。
- **音阶**：各调的大调、三种小调、半音阶和大小调琶音，一到四个八度，单手、双手或从同一个主音出发的双手反向，标有哈农（Hanon）的指法。可以按自己的速度弹，也可以跟着节拍器弹（♩ = 40–160，每拍两、三或四个音，先有一小节预备拍）。弹完能看到时间上有多均匀（对照职业钢琴家的 8–9 毫秒）、力度和连奏如何、拇指穿过的地方是早是晚；跟节拍器时还能看到你偏早还是偏晚。薄弱的地方可以截取前后几个音循环练习。每一遍都会保存，并有 30 天趋势和下一条建议练习的音阶。
- **节拍器**：梅尔策尔式摆锤在你听到的拍点正好摆过中线，滑块位置随速度升降；20–300 BPM，敲击测速、拍号、重音与静音拍、细分、三种音色、只看不响，还有逐渐加快和静音小节两种速度训练。弹奏、识谱和练曲时，页头的小按钮就能开关，并可一键设为曲目的速度；节奏模式会先暂停它。
- **练习记录**：今日分钟数、连续打卡天数和最近 30 天的图表。
- 界面支持 English、简体中文、繁體中文、日本語、한국어。音名在所有语言里都用字母（C4、F♯）。

## 使用要求

- 电脑上的 Chrome 或 Edge（支持 Web MIDI）。其他浏览器可以用电脑键盘或鼠标弹。
- MIDI 键盘推荐但不是必需的，用 USB 线连接即可。
- 不需要账号。数据可以在“设置”里导出为 JSON 文件备份或迁移。
- playdacapo.com 用 Cloudflare Web Analytics 统计访问量：不用 cookie，不收集个人数据，也不涉及你的练习记录。Apple app 和其他构建都没有统计。
- 也可以用邮箱和验证码登录，通过 dacapo 的同步服务在你的各台设备之间同步练习（[隐私政策](https://playdacapo.com/privacy)）。在“设置”里删除账号会清除服务上的全部数据。
- 登录后还可以发布一个公开主页，像 GitHub 个人主页那样展示你一年的练习：可以只公开练习图，也可以同时公开每天练了什么。默认关闭，由你决定是否开启（[docs/PROFILE.md](docs/PROFILE.md)）。

## 开发

需要 Node.js 22.13 以上和 pnpm（版本见 `package.json` 的 `packageManager`）：

```sh
pnpm install
pnpm dev
```
