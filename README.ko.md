# dacapo

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) ·
한국어

_Da capo_ — “처음부터”.

dacapo는 MIDI 키보드로 피아노를 연습하는 오픈 소스 웹 앱이에요. 진짜 큰보표로 악보 읽기를 연습하고, 음마다 반응 시간을
기록해서 약한 음을 히트맵으로 보여 줘요. 진짜 악보로 곡도 연습할 수 있어요(기다리기 모드와 리듬 모드). 모든 데이터는
브라우저에 저장되고, 로그인하면 내 기기끼리 동기화할 수도 있어요.

**바로 써 보기:** [playdacapo.com](https://playdacapo.com/) — 설치할 필요도, 계정을 만들 필요도 없어요.

## 기능

- **악보 읽기 플래시 카드**: 큰보표에 나온 음을 옥타브까지 맞춰 건반에서 쳐요. 가운데 C 자리부터 덧줄, 올림표와
  내림표까지 7개 레벨이 있어요. 답할 때마다 정답 여부와 시간을 기록하고, 느리거나 헷갈리는 음이 더 자주 나와요.
  악보 읽기에는 **음악 이론 카드**도 있어요. 두 음 사이의 음정 맞히기(겹올림표·겹내림표까지), 조표의 으뜸음 치기,
  화음을 적힌 그대로 치거나 이름 맞히기, 각각 레벨이 따로 있어요. **리듬**도 있어요. 한 줄 보표의 리듬을
  한 마디 예비 박 뒤에 아무 건반이나 두드려 치면, 모든 음을 클릭과 비교해 재요. 4분음표부터 붙임줄, 16분음표,
  셋잇단음표, 당김음, 8분의 6박자, 양손으로 두 리듬까지 10개 레벨이에요. **초견**도 있어요.
  큰보표에 처음 보는 짧은 곡이 만들어지고, 오른손 C 포지션부터 조표 4개까지의 왼손 화음까지 8개 레벨이에요. 몇 초 훑어본 뒤
  박자에 맞춰 한 번에 치고(미리 보기로 한 음씩 칠 수도 있어요), 친 마디를 가려 앞서 읽기를 연습할 수도 있어요. 다 치면
  마디별 결과를 봐요.
- **청음**: 음정과 화음을 귀로 구별해요. 옥타브, 5도, 장3도부터 겹음정, 전위 화음, 7화음까지 12레벨. 악기나 내장
  피아노가 문제를 들려주면 건반으로 쳐서 답하거나(첫 음이나 근음이 표시돼요) 이름을 골라 답해요. 다음 문제는 자주 틀리는
  것부터 나와요. **선율**에서는 조의 으뜸화음 뒤에 짧은 선율이 나와요. 순차 진행하는 세 음부터 단조와 반음계적인 음까지
  7레벨. 한 음씩 따라 치고, 틀리면 선율과 친 음이 오선에 그려져요. **리듬**에서는 한 마디 클릭 뒤에 한 건반으로
  한 마디 리듬이 울려요. 악보 읽기 리듬의 처음 8레벨로, 박에 맞춰 두드려서 답하거나 리듬꼴 하나만 다른 마디들 가운데서 골라요. 기록 페이지에서는 문제 종류(청음과 이론 카드)마다
  레벨, 가장 약한 항목, 정답 대신 고른 답의 표(예: “단6도 — 내 답: 완전5도, 12번 중 4번”)를 볼 수 있어요.
- **화성: 코드 기호로 치기**: 리드 시트처럼 적힌 코드 기호(`Am`, `G7`, `F/A`, `Dm7♭5`)의 음을 아무 옥타브, 아무
  배치로 쳐요. 슬래시 코드는 베이스를 가장 아래에. 다장조·사장조·바장조의 3화음부터 열두 근음의 3화음과 7화음, 슬래시
  코드, `°`·`+`·`sus`·`6`·`add9` 코드까지 5레벨. 모든 답의 시간을 재고 느린 것일수록 더 자주 나오며, 힌트로 구성음도 볼
  수 있어요. **코드 진행**(`I–IV–V–I`, `ii7–V7–Imaj7`, 12마디 블루스 등)은 어떤 조로든 악보가 되고, 왼손은 반주
  형태(블록 코드, 알베르티 베이스, 왈츠, 스트라이드 등), 오른손 화음은 되도록 적게 움직이며 이어져, 곡처럼 연습할 수 있어요. 청음 페이지에서는 종지도 들어요: 화음 네 개 뒤에 정격·변격·반종지·거짓 종지를 골라요. **즉흥 연주**: 반복되는 반주(12마디 블루스, `I–vi–IV–V`, `ii–V–I`, 모달 뱀프. 스트레이트나 스윙) 위에서 치면 코드가 차례로 보이고, 건반에 추천 스케일이 표시되며, 친 음은 코드 톤·스케일 음·스케일 밖으로 색이 나뉘어요. 콜 앤드 리스폰스도 있어요. 멈추면 점수 대신 피드백을 보여 주고, 테이크를 반주와 함께 다시 들을 수 있어요.
- **약한 음 히트맵**: 오선보나 건반 위에 음을 찾는 속도를 색으로 보여 줘요.
- **곡 연습**: 퍼블릭 도메인 곡 21곡(그중 8곡은 민요·찬송가·영가 선율에 코드 기호를 붙인 리드 시트로, 왼손은 고른 반주 패턴으로 코드 기호에서 만들어 낮은음자리표 보표에 적어 줘요)이 들어 있고, 내 MusicXML도 가져올 수 있어요. 기다리기 모드에서는 맞게 칠 때까지
  커서가 기다리고, 리듬 모드에서는 메트로놈에 맞춰 친 뒤 빠르거나 늦은 경향과 빨라지거나 느려진 구간을 알려 줘요.
  들어 보기와 반대 손은 악기가 MIDI로 연주하고, 악기에 MIDI 출력이 없으면 내장 샘플 그랜드 피아노(Salamander Grand
  Piano)가 연주해요. 컴퓨터 키보드와 화면 건반도 이 피아노로 소리가 나요. 어떤 연주든 친 그대로 다시 들을 수 있고,
  악보가 따라가며 틀린 음은 친 자리에 표시돼요. 악보대로의 소리와 마디마다 비교할 수도 있어요. 끝까지 친 곡은 하루,
  이틀, 나흘, 일주일 뒤에 복습하러 돌아오고, 잘 치는 동안에는 간격이 두 달까지 늘어나요. 암보 모드에서는 악보가
  마디마다 가려지고, 필요할 때 살짝 볼 수 있어요. 어느 곡이든 위아래로 반음 6개까지 조옮김할 수 있고, 악보를 새 조로 다시 그려
  듣기와 반주, 판정도 그 조로 해요.
- **스케일**: 모든 조의 장음계, 세 가지 단음계, 반음계, 장·단3화음 아르페지오를 1–4옥타브, 한 손, 양손, 또는 한
  으뜸음에서 시작하는 반진행으로 쳐요. 하농의 손가락 번호가
  붙어 있어요. 내 빠르기로 쳐도 되고, 클릭에 맞춰 칠 수도 있어요(♩ = 40–160, 한 박에 2·3·4음, 예비 박 한 마디). 치고
  나면 시간이 얼마나 고른지(프로 피아니스트의 8–9ms와 비교), 음량과 레가토, 엄지가 넘어가는 곳이 늦거나 빠른지 보여
  주고, 클릭에 맞춰 쳤다면 빠르거나 늦은 경향도 알려 줘요. 약한 곳은 앞뒤 몇 음을 구간 반복으로 연습할 수 있어요. 모든
  연주를 저장하고, 스케일별 30일 추이와 다음에 연습할 스케일을 알려 줘요.
- **테크닉**: 모든 조의 5손가락 연습, 하농 1–20번(음, 마디, 손가락 번호 모두 1900년 판본 그대로이며 두 번 옮겨 적어 대조했어요), 으뜸3화음의 동시 화음(2–3옥타브)과 펼친 화음(1–2옥타브), 같은 책의 7화음 아르페지오, 동음 반복, 트릴, 3도 겹음, 옥타브(24개 조의 옥타브 음계), 그리고 원하는 조에서 원하는 두 손가락으로 치는 트릴을 쳐요. 재는 방법은 스케일과 같고, 화음은 가장 먼저 누른 건반으로 시간을 재며 건반끼리 얼마나 어긋났는지, 맨 위 음이 두드러졌는지도 보여 줘요. 트릴은 빠르기의 변화와 두 손가락이 고른지, 동음 반복은 다시 치기 전에 건반이 얼마나 올라와 있었는지 보여 줘요. 하농의 음형에서는 각 묶음의 같은 자리 음을 짚어 줘요.
- **메트로놈**: 메트로놈 진자가 들리는 박에 정확히 가운데를 지나고, 추는 빠르기에 따라 오르내려요. 20–300 BPM,
  두드려서 빠르기 맞추기, 박자, 강세와 음소거 박, 세분, 음색 세 가지, 화면만 모드, 점점 빠르게·무음 마디 트레이너가 있어요.
  연주·악보 읽기·곡 연습 중에는 헤더의 버튼으로 켜고 끄며, 곡 빠르기로 한 번에 맞출 수 있어요. 리듬 모드는 이를 잠시 멈춰요.
- **연습 기록**: 오늘 연습한 시간, 연속 연습일, 최근 30일 그래프. “실력 추이”는 연습마다 최근 반년을 주 단위로 그리고(악보 읽기 속도, 초견, 이론, 청음, 리듬 듣기, 코드 기호, 박자 정확도, 스케일의 고른 정도, 곡을 처음에 맞게 친 비율), 최근 4주가 그 전 4주와 비교해 어떤지 글로 알려 줘요. 레벨이 다르면 레벨별로 비교해요.
- 화면 언어: English, 简体中文, 繁體中文, 日本語, 한국어. 음이름은 모든 언어에서 알파벳(C4, F♯)으로 써요.

## 필요한 것

- 컴퓨터의 Chrome이나 Edge(Web MIDI 지원). 다른 브라우저에서도 컴퓨터 키보드나 마우스로 칠 수 있어요.
- MIDI 키보드를 추천하지만 꼭 필요하지는 않아요. USB 케이블로 연결하면 돼요.
- 계정은 필요 없어요. 데이터는 설정에서 JSON 파일로 내보내 백업하거나 다른 컴퓨터로 옮길 수 있어요.
- playdacapo.com은 Cloudflare Web Analytics로 방문 수를 세요. 쿠키를 쓰지 않고, 개인 정보나 연습 기록은 수집하지 않아요. Apple 앱과 다른 빌드에는 분석 기능이 없어요.
- 이메일 주소와 받은 코드로 로그인하면 dacapo 동기화 서비스를 통해 내 기기끼리 연습 기록이 동기화돼요([개인정보 처리방침](https://playdacapo.com/privacy)). 설정에서 계정을 삭제하면 서비스에 있는 데이터가 모두 지워져요.
- 로그인하면 GitHub 프로필처럼 1년 동안의 연습을 보여 주는 공개 페이지도 만들 수 있어요. 연습 격자만 공개하거나, 날마다 무엇을 연습했는지까지 공개할 수 있어요. 직접 켜기 전까지는 공개되지 않아요([docs/PROFILE.md](docs/PROFILE.md)).

## 개발

Node.js 22.13 이상과 pnpm(버전은 `package.json`의 `packageManager`)이 필요해요.

```sh
pnpm install
pnpm dev
```

기준이 되는 설명은 영어 [README](README.md)예요. 기여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)(영어), 번역은
[docs/TRANSLATING.md](docs/TRANSLATING.md)를 보세요.
